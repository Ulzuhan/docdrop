# DocDrop 3.1.2

Maintenance release for verified image publication and rollback.

- Includes the reviewed rollback baseline from [PR #7](https://github.com/Ulzuhan/docdrop/pull/7). CI verifies its exact signed digest, source, publication run and attempt before building the candidate.
- The image declares and tests rollback to the published **3.1.1** image, digest `sha256:1cb3d1dd91baf523e33cd244c3b6e583404358de843c5de36e54d0c8c5729f34`, using the same current synthetic store before and after the candidate. The separate Node 2.3.1 compatibility regression remains.
- Application source, frontend, API, dependency declarations and persisted data format are unchanged from 3.1.1. The store contract remains `go-json-v1`; this release introduces no data or configuration migration.
- Release CI tests and scans one OCI artifact, verifies its provenance, signs its exact digest and promotes the same bytes without rebuilding. Images are rebuilt from the declared base images and current OS packages, so image contents can differ even when application source is unchanged. This release must pass its own release gates.

Pin the published **3.1.2 digest** for deployment. Publishing also advances the floating `3.1`, `3` and `latest` aliases; those aliases do not replace digest review. Preserve the current store when rolling back: never restore spent download counters, tombstones or revocations from an older backup.
